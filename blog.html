🔑 Admin Publishing Guide

Option A: Publish Automated AI Drafts

  1. Go to the GitHub Pull Requests page.
  2. Open the draft, click the **Pencil icon** (edit), write edits under the **Preview** tab, and click **Commit**.
  3. Click **Ready for review** and then **Merge pull request**.
  4. That's it! GitHub will automatically deploy it live in 30 seconds. (No local commands needed!).

Option B: Create & Delete Articles (Dashboard)

  1. Double-click **create-post.bat** in your project folder.
  2. The **Blog Admin Dashboard** will open in your browser automatically.
  3. Create: Fill in the fields, write using the visual toolbar, and click Publish & Sync Live.
  4. Delete: Click the red Delete button next to any article in the listing.
